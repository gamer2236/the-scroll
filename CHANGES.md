# Changes

User-facing additions to The Scroll reader:

1. **Jump to passage** — Footer control (list icon) opens a dark picker to choose Book → Chapter → Verse, then Go navigates to that page and scrolls to the verse when possible.
2. **Copy verse / paragraph** — Each verse shows its number and a Copy control; clipboard text is formatted like `Genesis 1:1 — …`. When a chapter has only paragraphs, each paragraph can be copied with a book-and-chapter reference.
3. **Watermark** — Soft top label "The Time Traveler Bible" (muted, low opacity, non-interactive).
